# Product vision

ShieldTester separates a versioned DRS engine, campaign orchestration and independently sourced evidence. It supports simulated IoT clients without treating a virtual client as a physical machine or distinct public source.

The three modes are engine validation (software events only), synthetic laboratory (experimental traffic and declared limitations), and measured evaluation (qualified independent evidence). Reports always disclose reference version, interpretation profile, coverage, requested and achieved conditions, impact, recovery and missing dimensions. A completed campaign can remain inconclusive.

DRS 3.00.00 is archived as an immutable catalogue. WRS is a separate diagnostic. The application does not issue Red Button certification. See [DRS engine](drs-engine.md).

The immediate usable product is the three-agent HTTP laboratory and offline assessment workflow. The registry can describe 5,000 devices/100 sites; scaled physical execution and Kusa are future qualified integrations. See [current setup](current-setup.md) and [roadmap](roadmap.md).
