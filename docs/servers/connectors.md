# Measurement connectors

Legacy protection and target telemetry providers support configured pull/push JSON sources. Protection timing/source and target NIC counters retain provenance; a fallback estimate is not independently measured data. Runtime `/health` reports configuration availability, not complete DRS instrumentation.

The independent HTTP probe path includes quality/resource diagnostics. A basic successful status response does not validate a functional user journey. DRS declares generator, protection-entry, user and origin roles and separately qualified calibration/time/source evidence. These roles are not fulfilled merely by enabling a legacy provider.

Kusa API/schema/auth and real entry/origin/functional collectors remain pending. Do not fabricate endpoint names or mark integration complete. See [measurement](../measurement.md), [DRS engine](../drs-engine.md), [handoff](../infrastructure-handoff.md) and [roadmap](../roadmap.md).
